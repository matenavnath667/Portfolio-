# Navnath Mate — Developer Portfolio

A responsive dark-first portfolio site built with plain HTML, CSS and JavaScript. It includes the uploaded portrait and resume PDF, animated role text, responsive navigation, theme toggle, project filters, and a contact form that prepares an email draft without pretending to submit it to a server.

## Run locally

Open `index.html`, or run `python -m http.server 8000` from the repository root and visit `http://localhost:8000`.

## Update your portfolio

- Replace `assets/navnath-mate.png` with your current portrait.
- Replace `assets/navnath-mate-resume.pdf` with your updated resume.
- Add real certificate files and credential links before listing certificates.
- Update project cards and repository/live-demo URLs in `index.html`.
- The contact form uses `mailto:matenavnath667@gmail.com`; it does not send data to a web server.

## GitHub Pages deployment

1. Open repository **Settings → Pages**.
2. Choose **Deploy from a branch**, set branch to `main` and folder to `/ (root)`, then Save.
3. Wait for the Pages build and open the URL shown on that settings page.

## Vercel deployment

Import this repository into Vercel as a static/Other project. Leave build command empty and use `.` as the output directory.

## Notes

Resume-based education, skills, projects and internship details are used. No certifications are fabricated. Test links and layout on mobile and desktop after publishing.
